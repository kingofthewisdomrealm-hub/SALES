# SALES — The Full Conversation

A **Jeremy Miner–style NEPQ trainer**: you run one sale from the first knock to the signed next step, and you can see **what each person is thinking** while they talk.

Play it: open `index.html` in a browser (needs `styles.css`, `data.js`, and `engine.js` next to it).

This is **not** a remake of [Knockandrestore](https://github.com/kingofthewisdomrealm-hub/Knockandrestore). That game taught porch pressure with a Game Boy frame, six generic buttons, and a walking street. This trainer teaches the **whole conversation** — connection before situation, problem ownership before the pitch, commitment before the presentation — with thought bubbles, a visible process rail, and a debrief.

## What you practice

0. Approach  
1. Connection  
2. Situation  
3. Problem awareness  
4. Solution awareness  
5. Consequence  
6. Commitment  
7. Presentation  
8. Next step

NEPQ is used here as a **public teaching model**: questions first, pitch last, buyer says the close. Scripts are original. They are not 7th Level course material.

## How a round works

- Pick Dale (guarded) or Gene (burned).
- **Learn** shows both thought bubbles and the coach note. **Practice** hides the seller’s inner coach.
- Scene 1 is the porch. A real commitment question unlocks Scene 2 — the kitchen table after findings.
- Each line is scored for phase fit. Orange tags are early or late. Green coach notes are on time.
- Thought clouds above the heads are the lesson: speech vs. the unspoken.
- The debrief lists which flags the buyer actually spoke (problem, want, cost, intent) and one rewrite.

## Winning path (Learn, Dale)

Connection → Situation (the hall stain) → Problem (they name the spread) → matched proof → Commitment (want the look) → Recap findings → Solution (“handled”) → Consequence → Commitment → matched scope → Thursday or Saturday.

Pitching the package on the welcome mat, diagnosing from the yard, or asking for a deposit on Gene will raise the wall.
